## [1.0.0] - 2026-11-16

Первый стабильный релиз.

### Добавлено

- **backup / restore / verify / list / secrets** — полный цикл миграции среды
  MiMoCode между Linux-машинами через USB-архив.
- Интерактивный мастер без аргументов: авто-определение контекста (данные
  mimocode / архивы рядом), вопросы с дефолтами, выбор при живой mimo
  («остановить и продолжить / выйти»).
- Секреты в отдельном архиве с опциональным паролем: Argon2id (64 МиБ, t=3)
  + AES-256-GCM, контейнер `.mimosec` v2 с защитой от cost-бомб.
- Политика пароля: `A–Z a–z 0–9`, мин. 5, двойной ввод при создании.
- Обеззараженные копии конфигов (`***REDACTED***`) в основном архиве —
  проекты не остаются без конфигурации при restore без секретов.
- Контроль целостности: sha256 каждого файла, `archive_sha256`,
  `verify --quick` / `--full`.
- Потоковая архитектура: hash-while-write, один проход, O(1) память на файлы.
- Лента прогресса 0–100% с ETA (EWMA), авто-off без TTY, `--no-progress`.
- Дата/время — обязательная часть имени артефакта.
- Восстановление: safety-копии `.pre-restore-*`, журнал `.restore-journal.jsonl`,
  выборочный restore (данные / + секреты).
- Снапшот БД `VACUUM INTO` (hot) или cold-copy `db+wal+shm`.
- bash-completion, SKILL.md для агентов MiMoCode.
- **Поддержка macOS**: universal-инсталлятор `.pkg` (Apple Silicon + Intel),
  терминальный ввод без эха через TIOCGETA, детектор процессов через `ps`
  (fallback без /proc).

### Безопасность

- SQL-экранирование путей в `VACUUM INTO` (метки USB недоверенные).
- Zip-slip защита (включая symlink-родителей), `O_NOFOLLOW`.
- Границы KDF-параметров при Open контейнера.
- Пароль и ключи не пишутся в логи/манифест.
