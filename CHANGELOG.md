# Changelog

Все заметные изменения этого проекта документируются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.1] - 2026-11-16

### Исправлено

- `--help` печатает справку один раз и завершается с кодом 0 (раньше справка
  выводилась дважды с кодом 1).
- Закрытие ввода (Ctrl-D / пустой stdin) в мастере — дружелюбная отмена
  «ввод завершён — отменено» с кодом 0 вместо `ERROR EOF` с кодом 1.

## [1.1.0] - 2026-11-16

Умное восстановление: git-подобный откат вместо разбросанных `.pre-restore-*`.

### Добавлено

- **`mimo-backup rollback`** (`rb`) — откат последнего восстановления:
  удаление записанного и возврат отодвинутых путей, дерево восстанавливается
  байт-в-байт (файлы, симлинки, каталоги, mtime).
- **Поколения** в `~/.mimo-backup/generations/<id>`: `meta.json`,
  `displaced/`, `extracted.jsonl` (журнал каждой записи, crash-safe).
- **Git-история настроек** (`~/.mimo-backup/settings-repo`): копии
  `~/.config/mimocode/**` и rc-файлов; коммиты `pre-restore`/`post-restore`/
  `pre-rollback`; правки пользователя сохраняются перед откатом.
- **`mimo-backup history`** (`h`) — поколения и git-лог настроек.
- **`mimo-backup cleanup`** (`c`) — ретеншн поколений (`--keep N`, `--all`).
- **`mimo-backup fix-nested`** (`fn`) — починка машин, восстановленных v1.0.0
  (баг с вложенностью `~/home/`): dry-run по умолчанию, `--apply` для правок.
- **`backup --encrypt`** — весь архив в один контейнер `.mimosec`
  (данные + опись + секреты, без sidecar); потоковое шифрование (MIMOSEC2,
  чанковый AES-256-GCM, O(1) памяти).
- Мастер: пункты «Откатить последнее восстановление», «Посмотреть историю»,
  «Починить ~/home»; вопросы бэкапа: секреты → шифрование всего архива →
  пароль только для секретов.

### Исправлено

- **Баг A (критический)**: распаковка клала файлы в `$HOME/home/…` вместо
  `$HOME/…` (на ноутбуках после переноса проекты оказывались в
  `~/home/projects`). Записи без префикса `home/` теперь отклоняются.
- **Баг B**: журнал восстановления удалялся при сбое — теперь переживает
  ошибку, и `rollback` работает после неудачного restore.
- **Баг C**: страховка отодвигала целые топ-уровни (`.local`, `.config`) и
  съедала пропускаемые файлы (`.bashrc`, `installation_id` исчезали из
  `$HOME`). Displacement теперь равен набору записи: только реальные корни
  восстановления, пропускаемые пути не трогаются.
- **Баг D**: шифрование секретов определялось по суффиксу файла, а не по
  магии контейнера; заявленный, но ненайденный архив секретов был лишь
  информационным сообщением (теперь ошибка); `-secrets.tar.gz` классифицировался
  как основной архив; пароль запрашивался в конце распаковки (теперь в начале);
  `m.SecretPaths` не содержал secret-only файлы (манифест был неполным).
- **Баг E (новый)**: при `vacuum-into`-снапшоте в архив попадали застаревшие
  `mimocode.db-wal`/`-shm` от живой базы и «смазывали» снапшот при открытии
  (симптомы: read-only, пропавшие сессии). Теперь не архивируются и не
  распаковываются.
- **Переносимость macOS**: защита от symlink-parent проверяет только путь
  внутри целевого дома (раньше отвергалась легитимная пара `/var` →
  `/private/var`); zombie-детект процессов без `/proc` через `ps`; ввод
  пароля без TTY терпит `ENODEV`/`EOPNOTSUPP` (не только `ENOTTY`).
- `--yes` принимается после подкоманды (`rollback --yes`), а не только до неё.

## [1.0.0] - 2026-11-16

Первый стабильный релиз.

### Добавлено

- **backup / restore / verify / list / secrets** — полный цикл миграции среды
  MiMoCode между Linux-машинами через USB-архив.
- Интерактивный мастер без аргументов: авто-определение контекста (данные
  mimocode / архивы рядом), вопросы с дефолтами, выбор при живой mimo
  («остановить и продолжить / выйти»).
- Секреты в отдельном архиве с опциональным паролем: Argon2id (64 МиБ, t=3)
  + AES-256-GCM, контейнер `.mimosec` v2 с защитой от cost-бомб.
- Политика пароля: `A–Z a–z 0–9`, мин. 5, двойной ввод при создании.
- Обеззараженные копии конфигов (`***REDACTED***`) в основном архиве —
  проекты не остаются без конфигурации при restore без секретов.
- Контроль целостности: sha256 каждого файла, `archive_sha256`,
  `verify --quick` / `--full`.
- Потоковая архитектура: hash-while-write, один проход, O(1) память на файлы.
- Лента прогресса 0–100% с ETA (EWMA), авто-off без TTY, `--no-progress`.
- Дата/время — обязательная часть имени артефакта.
- Восстановление: safety-копии `.pre-restore-*`, журнал `.restore-journal.jsonl`,
  выборочный restore (данные / + секреты).
- Снапшот БД `VACUUM INTO` (hot) или cold-copy `db+wal+shm`.
- bash-completion, SKILL.md для агентов MiMoCode.
- **Поддержка macOS**: universal-инсталлятор `.pkg` (Apple Silicon + Intel),
  терминальный ввод без эха через TIOCGETA, детектор процессов через `ps`
  (fallback без /proc).

### Безопасность

- SQL-экранирование путей в `VACUUM INTO` (метки USB недоверенные).
- Zip-slip защита (включая symlink-родителей), `O_NOFOLLOW`.
- Границы KDF-параметров при Open контейнера.
- Пароль и ключи не пишутся в логи/манифест.
